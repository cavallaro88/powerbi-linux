## Changelog

- Extend the normal resizable/unowned Desktop client to its complete frame. Replace the visible 4-pixel side/bottom gutters with transparent native resize input zones, preserving styles and fixed/owned/native-maximized calculations.
- Guard the two patched methods by exact contents and sign the helper locally. Setup/repair records its checksum; doctor checks the frame patch. Modified Microsoft binaries stay local.
- Native and actual-base-class fixtures passed frame, hit-target and owned/fixed controls. A managed compositor drag passed; normal Desktop measured zero insets, and the visual fix was confirmed with working mouse/shortcuts. Actual compositor maximize-state divergence also reproduces on baseline and remains separate coverage, as do other display scales and broader modal workloads. See [evidence](https://github.com/cavallaro88/powerbi-linux/blob/main/docs/reference/window-frame.md).
- Apply the candidate locally without cloning the profile or changing the runtime/resource policy; retain the old DLL/manifest for rollback.

## Assets and installation

The original CLI RPM and its source RPM are attached with SHA-256 checksums.
They contain project tools and recipes, not Power BI, populated prefixes,
credentials or the patched Wine runtime. Microsoft installers and runtimes
are provisioned separately under their own terms.

```bash
sudo dnf install ./powerbi-linux-0.1.0-12.noarch.rpm
# Existing CLI installation:
sudo dnf upgrade ./powerbi-linux-0.1.0-12.noarch.rpm
pbi-linux doctor
```

RPM updates alone do not replace the user's runtime or patch a running Desktop.
Read the maintenance guide before repair.
