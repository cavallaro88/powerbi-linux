## Assets and installation

The binary RPM, matching source RPM, `SOURCE-PROVENANCE.json` and `SHA256SUMS`
are attached. The package includes project tools and patch recipes. Power BI,
modified Microsoft files, populated profiles, reports and Wine runtime binaries
are not included. Packages are unsigned; checksums provide integrity checks.

```bash
sudo dnf install ./powerbi-linux-0.1.0-13.noarch.rpm
# Existing CLI installation:
sudo dnf upgrade ./powerbi-linux-0.1.0-13.noarch.rpm
pbi-linux doctor
```

RPM upgrades alone do not patch an existing profile. Close Desktop and follow
the [maintenance guide](https://github.com/cavallaro88/powerbi-linux/blob/main/docs/user/install.md)
before repair, including its snapshot disk requirements. No Wine rebuild is
needed for this text-picker correction. Runtime and optional resource settings
retain their existing policy. See the [validation and scope](https://github.com/cavallaro88/powerbi-linux/blob/main/docs/reference/text-pickers.md).

Source and binary payloads were compared before upload. No broader runtime/UI
release certification is implied. This is an independent community project,
without official Microsoft support. Keep private report/model backups; license
notices and component-specific terms remain in the source tree.
