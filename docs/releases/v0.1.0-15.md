# Options interaction correction — RPM 15

Local candidate date: **2026-10-21**.

RPM `0.1.0-15` contains guarded corrections for Desktop 2.158.1177.0 and 2.159.883.0:

- Advertise native resizing for the Options window, preserving fixed and unrelated dialogs.
- Fit navigation and content to the viewport, keep the footer visible and make
  the final sidebar item reachable by scrolling.
- Prevent label selection while retaining selection/editing in input fields.
- Preserve the original tab, keyboard, maximize and save/cancel callbacks.

Close Desktop, install the matching package and run `pbi-linux repair` to update
an existing profile. Repair creates a managed snapshot; allow space for another
complete installation. A new Wine/DXVK runtime is not required.

This package was built locally without CI or publication. A simulated 3440×1440
viewport does not certify that physical compositor/display combination. See
[technical scope](../reference/options-dialog.md#october-21-options-resizing-and-selection).
