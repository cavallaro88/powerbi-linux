# Local tooltip correction — RPM 16

Local candidate date: **2026-10-23**.

Simple browser title tooltips now render inside WebView rather than through a
detached native window. The recipe covers HTML titles, SVG titles and same-origin
visual frames. Original rich data tooltip handlers remain in control.

Close Desktop, upgrade the project package and run `pbi-linux repair` as your
normal user. A new runtime is not required. Repair creates a managed snapshot;
allow approximately 9 GiB additional space for a complete installation copy.

See [implementation, evidence and limits](../reference/intermittent-popup.md).
Packages are built locally without CI or publication. This is not certification
of every custom visual, tooltip report page or session.
