# Local GNOME theme integration — RPM 17

Local candidate date: **2026-10-23**.

This local beta updates the project tools to follow GNOME when Desktop's theme
selection is **System default** (**Padrão do sistema**). Explicit Light/Dark
selections are preserved. The preference is applied before the first document
opens, then checked every two seconds while the managed session is running.

Close Desktop normally, keeping any report changes you want to save. From the
repository root, install the local binary RPM:

```bash
sudo dnf upgrade ./dist/gnome-theme-0.1.0-17/powerbi-linux-0.1.0-17.fc44.noarch.rpm
pbi-linux doctor
pbi-linux open
```

No repair or runtime replacement is required. Select **Padrão do sistema** in
Desktop and use GNOME's appearance setting to switch between light and dark.

Validation: 152 unit tests passed, including eight theme bridge tests. Thirteen
native assertions passed with Desktop 2.159.883.0 and runtime 0.1.5, using a
synthetic WinForms receiver and the original Desktop ThemeService. The Python
startup/compiler path also passed. Full visible Desktop, Power Query and other
versions remain separate validation gates. See the [implementation and native
test instructions](../reference/gnome-theme.md).

This is a local build from the current working tree, including the earlier
Options, tooltip and platform changes already used by RPM 16. It is not a public
release or a CI-certified artifact. Source RPM and checksums accompany the local
binary; Microsoft installers and populated profiles are not packaged.
