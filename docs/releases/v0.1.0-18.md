# RPM 0.1.0-18 — automatic setup and update

Published on **October 25, 2026** as a development prerelease.

- `pbi-linux setup` resolves the published Runtime 0.1.5, its complete
  corresponding source and exact-archive evidence, and the pinned Power BI
  installer from Microsoft. Every download is verified against a fixed SHA-256.
- `pbi-linux update` uses the same published runtime by default; explicit
  `--runtime` and `--runtime-sha256` remain available.
- Runtime 0.1.5 is published with its binary archive, corresponding source and
  evidence. The exact-archive two-hour soak remains pending, so no stable
  runtime certification is claimed.
- Remove the experimental Pop!_OS/DEB packaging path; the Fedora RPM is the only
  supported package format.
- No change to the guarded 2.158/2.159 recipes, existing profiles or
  installations.

## Assets and installation

The binary RPM, source RPM, `SHA256SUMS` and `SOURCE-PROVENANCE.json` are
attached to the GitHub release. See [installation](../user/install.md) and the
[setup release contract](../development/setup-release.md).
