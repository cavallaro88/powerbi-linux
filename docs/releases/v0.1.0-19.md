# RPM/DEB 0.1.0-19 — beta candidate (prepared, not published)

Status: **prepared in the source tree and not yet published.** This note describes
what the 0.1.0-19 packages would contain. No tag, release or asset exists for it at
the time of writing.

- RPM `0.1.0-19` and experimental DEB `0.1.0-19~experimental1` from the same CLI
  source; the DEB remains an experimental target (Ubuntu 24.04/26.04, Debian 13)
  and does not extend Fedora 44 validation.
- Both packages are **beta**: the setup pin, maintenance path and packaging are
  still changing and no stable certification is claimed.
- The setup manifest ships `status: pending`. Automatic setup is disabled until
  Runtime `0.1.6-beta.1` publishes its binary archive, complete corresponding
  source and exact-archive evidence with fixed URLs and SHA-256 values. The
  published Runtime 0.1.5 pin is not reused and no placeholder checksum is shipped;
  a locally verified archive can still be supplied with `--runtime` and
  `--runtime-sha256`.
- No Wine runtime, Microsoft installer, populated prefix or ODBC DLL is shipped.
- The experimental Redshift/ODBC bridge remains unpublished and is not activated
  by packaging. Repair and runtime updates do not restore an ODBC manager that is
  missing from an existing profile; see [Redshift scope](../reference/redshift.md)
  and [known issues](../user/known-issues.md).

## Assets at publication

Binary RPM, source RPM, DEB, matching source export, `SHA256SUMS` and
`SOURCE-PROVENANCE.json`. The DEB additionally keeps its `.deb.sha256` file.
Digests are recorded in the [release catalogue](../../packaging/releases.json)
only after the uploads are verified.

## Installation after publication

```bash
# Fedora 44
sudo dnf install ./powerbi-linux-0.1.0-19.noarch.rpm
# Ubuntu 24.04/26.04 or Debian 13 (experimental)
sudo apt install ./powerbi-linux_0.1.0-19~experimental1_amd64.deb
pbi-linux setup   # asks for terms; automatic runtime pin is pending in this build
```

Because this package ships a pending runtime manifest, `pbi-linux setup` without
`--runtime` refuses to download. Use a locally verified runtime archive, or stay on
RPM 18 until the 0.1.6-beta.1 assets are published and the manifest is updated.
