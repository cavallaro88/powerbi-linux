# Known issues and support limits

> [!WARNING]
> **Power BI Linux is beta software.** Keep a private backup of your complete project and work with copies first. For PBIP projects, include `.pbi/cache.abf`: a normal Git checkout excludes imported cached data. See [cache recovery](../reference/model-cache.md).

The tested platform is **Fedora 44 x86_64, native Wayland**, with a systemd user session and Vulkan graphics. Ubuntu 24.04/26.04 and Debian 13 are accepted only as [experimental DEB targets](debian-ubuntu.md), and Arch Linux and Omarchy only as an [experimental source package](arch.md); none is a certified platform. Other distributions and X11 are outside the current support target. Other Fedora versions are experimental.

## What has worked in recorded tests

Opening PBIX/PBIP/PBIR from the desktop; CSV import, visuals and save/reopen; a synthetic 158-table refresh and two-hour session; browser sign-in and persistence; and a confirmed publication to a test workspace. These are version-specific results, not a guarantee for every report. The [detailed compatibility matrix](../reference/compatibility.md) records the scope and versions.

## What may affect your work

| Feature | Status | Impact and next step |
|---|---|---|
| Installing from current published releases | Partial | RPM 18 enables automatic setup: `pbi-linux setup` downloads the published runtime, its matching source and evidence, and the pinned Microsoft installer, verifying every SHA-256. Earlier published previews need explicit local inputs. The published runtime is a beta candidate whose two-hour soak is pending. See [installation](install.md). |
| Automatic download of Power BI Desktop | Updated recipe in source; older releases still fail | Microsoft replaced the unversioned download with 2.160.1151.0. The source tree registers that exact build and keeps earlier exact installers for local inputs; older published pins still reject the current download. See [2.160 assessment and native validation limits](../reference/powerbi-2.160.md). |
| Published runtime 0.1.5 | Partial | Clean install, native components, a 158-table refresh, save/reopen and lifecycle checks passed on the exact archive; the two-hour soak remains pending. No stable runtime certification is claimed. |
| New Power BI Desktop versions | Not validated as a release | RPM 18 targets 2.159.883.0 and also accepts the exact 2.158.1177.0 installer; other installer hashes are rejected. Do not bypass checksum checks. |
| Legacy dialogs on Hyprland | Corrected in a local build, one host | The error report, Data source settings and other dialogs of the same family opened as a 2 x 2 pixel window while the main window stayed disabled, which looks like a frozen Desktop. A Wine correction gives them their size; no published runtime contains it. See [legacy HTML](../reference/legacy-html.md#dialogs-two-pixels-wide-on-hyprland-2026-11-18). |
| Options dialog on Hyprland | Corrected in the source tree for 2.159.1231.0 and 2.160.1151.0 after repair, one host | Options opened as an empty frame over a disabled Desktop. It now appears, at 600 x 400: resize it with the window manager, or add the window rule in [Options](../reference/options-dialog.md#november-21-options-was-an-empty-frame-on-hyprland) to open it at 1000 x 800. Run `pbi-linux repair` after updating. |
| OK does nothing in legacy dialogs | Corrected in the source tree for 2.159.1231.0 and 2.160.1151.0, one host | OK in Options, Export template, View as, connector warnings and about 15 more dialogs did nothing; Cancel worked. Run `pbi-linux repair` after updating; `pbi-linux doctor` reports `dialog-serializers`. See [legacy HTML](../reference/legacy-html.md#ok-did-nothing-in-most-legacy-dialogs-2026-11-21). |
| Report blank behind a modal dialog | Corrected in runtime 0.1.7-local.10 | While Options (or another modal dialog) was open, the main window could show an empty background until the dialog closed. See [Options](../reference/options-dialog.md#november-22-the-report-went-blank-behind-a-modal-dialog). |
| Floating or shrunken window on Hyprland | Corrected in a local build, one host | Desktop could start as a floating window slightly larger than the monitor, and its window could go back to a smaller size inside its tile after a workspace switch. Two Wine corrections; no published runtime contains them. See [Hyprland](../reference/hyprland.md#later-corrections-2026-11-18). |
| Scroll bars in Data source settings | Corrected for 2.159.1231.0 and 2.160.1151.0, one host | The dialog body showed two scroll bars that covered part of the sort button. A recipe step removes them after `pbi-linux repair`; 2.158.1177.0 and 2.159.883.0 are unchanged. See [legacy HTML](../reference/legacy-html.md#scroll-bars-inside-data-source-settings-2026-11-18). |
| Desktop does not close: "Auto recovery" dialog | Corrected for 2.159.1231.0 and 2.160.1151.0, one host | Closing Desktop with a recovered file that was never opened showed "Auto recovery", whose OK did nothing; Cancel cancelled the close, so Desktop stayed open. After updating, close Desktop (run `pbi-linux stop` if it is stuck) and run `pbi-linux repair`; `pbi-linux doctor` reports `auto-recovery-dialog`. See [legacy HTML dialogs](../reference/legacy-html.md#desktop-would-not-close-auto-recovery-dialog-2026-11-21). |
| Freeze after a resize | Corrected in a local build, one host | Desktop stopped reacting after a visual or column resize until the pointer shape changed, once for almost seven minutes. A Wine correction passed a forced reproduction; no published runtime contains it. See [cursor evidence](../reference/cursor.md#desktop-frozen-after-a-cursor-change-2026-11-18). |
| Opening a second report from Desktop | Corrected in the source tree, one host | Opening another report while one is open (File > Open, a recent file) or a restart from Desktop started a new Desktop that crashed at once with an access violation and a Wine "Program Error" window; the first Desktop kept running. A Desktop started from the file manager or `pbi-linux open` was not affected. After updating, close Desktop and run `pbi-linux repair`; `pbi-linux doctor` reports `desktop-instances`. A later correction keeps that second Desktop running after the first one closes; before it, the session ended about ten seconds later and took the second report with it. See [patches](../reference/patches.md). |
| Displays wider than 4096 or taller than 2304 pixels | Corrected in a local build, one host | Desktop stayed blank on such an output (an ultrawide 5120 x 1440 monitor, a 5K panel), with nothing in the session log. A Wine correction accepts frames up to the area of 7680 x 4320 and reports a larger one once; it passed on a 5120 x 1440 headless output only, and no published runtime contains it. See [patches](../reference/patches.md). |
| Opening two reports at once | Corrected in the source tree, one host | The second `pbi-linux open` (two files selected in the file manager, a second double-click during a cold start) failed with "Another maintenance operation is running". It now waits for the first to start the session. |
| Embedded Windows authentication broker | Known failure | Use the default system browser for Microsoft sign-in. See [sign-in](sign-in.md). |
| MySQL with explicit Windows username/password impersonation | Known failure | Wine's placeholder Windows token fails this flow. Database-password authentication passed in a local fixture; real-server TLS remains unvalidated. See [connectors](connectors.md). |
| General Get Data / OneLake chooser | Not validated | Direct Text/CSV import passed. The general chooser was blocked by sign-in and has not been revalidated after authentication. Use the direct CSV entry for the tested CSV path. |
| Data source settings list | Partial | Sources can appear before clicks respond; a delay of roughly 10–60 seconds was observed. The cause remains unresolved. See [source-list evidence](../reference/legacy-html.md). |
| Options window size and text selection | Local correction | RPM 15 adapts navigation/content to the window, preserve editable text and advertise native resizing. Close Desktop and run `pbi-linux repair` after installing the update. See [scope and validation](../reference/options-dialog.md#october-21-options-resizing-and-selection). |
| Intermittent small white window on hover | Local correction | RPM 16 shows browser HTML/SVG title tips inside WebView, including same-origin visual frames. Rich data tooltips retain their original handlers; full native visual/report-page validation remains pending. Install the package with Desktop closed, then run `pbi-linux repair`. See [scope and limits](../reference/intermittent-popup.md). |
| GNOME and Hyprland light/dark preference | Local correction | RPM 17 follows GNOME's color preference (the source tree also on Hyprland) while Desktop's theme selection is **System default**; explicit Light/Dark selections stay under Desktop's control. Restart Desktop after updating the RPM; no repair is required. Other desktop environments are not covered. See [scope and limits](../reference/gnome-theme.md). |
| Nested permission confirmations | Not validated | Main Edit Permissions OK/Cancel has scoped tests. Nested None/Delete confirmations still need validation. See [permissions](../reference/permissions-wayland.md). |
| ODBC manager missing from an existing profile | Known limitation | Repair and runtime update rewrite the managed runtime in place; they do not recreate an app-private ODBC manager that is already absent from a profile, and the experimental bridge is neither shipped nor activated. Restore the original driver/manager outside the project, then verify with `python3 tools/test-odbc-driver.py`. See [Redshift](../reference/redshift.md). |
| Redshift and external Windows ODBC installers | Partial / experimental | Controlled authentication, metadata and limited Import/Save/reopen passed. A general managed installation flow, other authentication modes and broader typed-data/TLS coverage remain pending. See [Redshift](../reference/redshift.md). |
| Refresh cancellation | Partial | Synthetic cancellation and user tests passed, but the originally reported freeze was not reproduced. Server-side cancellation and post-cancel data state are not generally certified. See [cancellation](../reference/refresh-cancellation.md). |
| Complex enterprise reports | Not validated | A reported original thin-report refresh ran out of renderer memory. The synthetic large-model pass does not cover every model's complexity. Keep originals and verify results independently. |
| Visuals after external diagnostic refresh | Known failure / unsupported flow | External processing can commit data without notifying visuals. Use Desktop's normal refresh flow; external TMSL processing is diagnostic only. |
| More than one monitor, Hyprland | Local correction, unpublished runtime | With runtime 0.1.6-beta.1 the window stays blank on a multi-monitor Hyprland desktop and the clipboard owner aborts. Four Wine corrections are in the source tree; they need a rebuilt runtime. See [Hyprland](../reference/hyprland.md). |
| PaperWM maximize/restore and display variations | Partial | Normal resizing has scoped candidate evidence. Maximize/restore divergence, multiple monitors and additional display scales need broader validation. See [window frame](../reference/window-frame.md) and [PaperWM](../reference/paperwm.md). |
| Cloud publishing | Partial | A real publication was confirmed. Broader account/workspace flows and a new cloud cycle after the Store-prompt correction remain unvalidated. See [publishing](publishing.md). |

**Known failure** means a problem was reproduced or reported in the recorded scope. **Partial** means only part of the flow has evidence or a workaround exists. **Not validated** means support has not been established; it does not claim the feature always fails.

## Before reporting a problem

Run `pbi-linux doctor` and consult [troubleshooting](troubleshooting.md). Include versions, sanitized diagnostic output and a synthetic reproduction in your [bug report](https://github.com/cavallaro88/powerbi-linux/issues/new/choose). Do not upload reports, model caches, credentials or populated installations.
